Executable test scripts
=======================

Python test sources live beside :doc:`../test-cases/index`. Run them from the
repository root with ``python -m pytest docs/test-scripts``. Fixture RST files
are test inputs, excluded from documentation discovery. Frontend tests remain
under ``frontend/test`` alongside their Node tooling.
