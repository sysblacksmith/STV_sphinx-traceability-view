Historical distribution license supplement
================================================================================

Scope and redistribution instructions
--------------------------------------------------------------------------------

This supplement supplies the project MIT license, full bundled third-party
notices and corresponding-source references for the retained STV archives
identified by SHA-256 below. It applies to STV-owned code and documentation
in these historical versions, including versions created before the license
file was added. Third-party components retain their own license terms.

The owner authorized remediation on 2026-10-24. This supplies missing licensing
materials for retained copies; it does not change the original archive bytes,
rewrite test evidence, or claim that earlier downloads have been recalled.
The former GitHub Releases have been removed. Historical archives remain
engineering evidence in Git and are no longer offered as documentation downloads.

When copying or redistributing an identified historical archive, accompany it
with this supplement's four files. For an installable distribution, prepare a
new corrected build carrying its notices internally; do not silently replace
an old archive under its historical hash or describe it as newly qualified.
For historical generated HTML, preserve these materials beside the browser
assets. New builds already carry the corrected materials automatically.

* :download:`STV MIT license <LICENSE.txt>`
* :download:`Complete third-party notices <THIRD_PARTY_NOTICES.txt>`
* :download:`Corresponding sources and build references <ELK-SOURCE.txt>`
* :download:`Pinned compiled dependency/source inventory <ELK-INVENTORY.json>`
* :download:`Machine-readable archive identities <artifacts.json>`

All retained historical ELK vendor copies match the same audited upstream
bundle. All available historical frontend lock files contain the same package
versions as the current lock. The complete supplement conservatively includes
all those npm contributions plus the previously missing compiled GWT, Guava,
EMF-GWT and Xbase/Xtend notices. The source notice carries exact upstream
ELK/ELK.js tags and dependency source archive URLs, with hashes in the inventory.
This is an engineering remediation record, not a claim of a legal opinion.

Verification: ``python scripts/historical-licenses.py`` checks retained archives
(including available unreachable local Git objects), the ELK fingerprint and
exact supplement bytes. Original source/test records and checksums are retained.
Removed hosted source-archive bytes were unavailable for inspection; no claim
is made that their content was verified or repaired. They are not republished.
